# 六结局与重读规则

2026-10-08，事实先于评分。玩家不选择结局标题，普通生活回应不改变录取、岗位、2013分开或双方现在的家庭。第十章没有新增“选择哪个人生”的按钮。结局是当前这一轮已经发生的联系、阅读与多年行为的不同收束，并非婚姻奖惩排名。

| 结局 | 必须先成立的事实 | 同级排序 |
|---|---|---|
| 好久不见 REUNION | 实际联系、实际会面、联系前说明、家里知道会面；选校、暑期、求职三处至少两次先听对方条件 | priority 20；honesty×0.2 + understandingXia×0.2 |
| 不要再见了 GOODBYE | 实际联系、实际谢绝见面、本次联系已关闭；第十章整理对话后没有追加私下约见 | priority 20；reality×0.3 + honesty×0.2；友善结束本次联系，不惩罚知夏 |
| 后来我才懂 UNDERSTAND | 完整信、完整录音来源、日期核对、陈野有限证词、理解分开事实全部成立；第十章实际分开整理来源 | priority 10；selfReflection×0.35 + reality×0.25 + understandingXia×0.20 + honesty×0.15 − avoidance×0.20 − regret×0.10 |
| 谢谢你陪我走到这里 TOGETHER | 第七章共同商量长期照看，第十章再次实际核当周分工，并继续做当前工作的事实 | priority 10；understandingPartner×0.45 + reality×0.20 + honesty×0.10 − avoidance×0.10 + 0.5；和 UNDERSTAND 同级比较 |
| 如果那年 IF_THEN | 没有符合上面更具体条件的路线 | priority 0；保留未知旧事和现在的生活，不回到2007改写他人命运 |
| 余生未寄 UNSENT | 至少三个不同的真实已完成结局、playCount≥2；本轮完整四来源/真相，首次等车/毕业/分开的核心记忆已重构，实际会面并读完第一页来源；读完第十章自己写的信 | priority 100；分数不能代替其中任何一项 |

分数只在事实候选之间比较。隐藏结局优先，明确行为结局其次，同级倾向结局再比较加权分数；精确相同使用配置固定顺序，不随机。65分和复杂模型不是正式设计，当前变化本来只有小幅1～2，不能设不可达的虚假高阈值。

结局页出现时尚未算读完，最后推进时才写 endings[id]、ROUND_COMPLETED、ROUND_END_id。重复推进同一个结局不增加计数。计数只认六个配置ID且只认 true，不计次数、未知键、打开过的页面或高分。

“再读一遍”先载入并验证开头资源，保存新轮成功后才替换正在使用的剧情。保留已完成 endings、metaFlags，完成过的轮次才加 playCount；重置本轮 flags、stats、readNodeIds、记忆来源、CG 和剧情位置，不能把上轮证据偷带进本轮。未完成时从首页重读保留元进度但不增加轮次。未来版本、旧集合备份失败、保存失败都保留原存档，不以删除进度实现二周目。

核心测试使用从开头实际推进的路线验证五个初始结局和三轮完成后的隐藏结局；实际H5连续六轮同一存档另有触摸验收记录。真人阅读和录音自然听感单列，自动流程不替代。
