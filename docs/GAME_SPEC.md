# 《余生未寄》商业规格摘要

## 产品定位
现实主义成人情感互动叙事 H5 游戏。

核心命题：
“我们怀念的究竟是那个人，还是和那个人在一起时年轻的自己？”

## 主要角色
- 周叙：47岁现实线主角，17岁青春线主角。缺点是习惯替别人做决定。
- 许知夏：初恋，17岁相识，喜欢摄影。不是白月光工具人，47岁也拥有完整人生。
- 程安然：周叙妻子，45岁。绝不是反派或替代品。
- 周满：16岁女儿，映照年轻时期的周叙。
- 陈野：高中好友，为过去提供另一份证词。

## 时间线
- 2007：17岁相识
- 2009：高中毕业，许知夏写“给未来的信”
- 2013：工作选择、车站分手
- 2017：周叙认识程安然
- 2020：结婚
- 2021：周满出生
- 2037：47岁收到迟到的信

## H5原则
- 竖屏 1080×1920
- 单手操作
- 单个 Story Segment 约 3～8 分钟
- 频繁自动保存
- 分段预加载
- 首屏资源轻量
- 重要互动：照片翻面、信件抽取、MP3播放、旧手机、记忆重构

## 商业化
V1.0 不依赖 IAP。
广告默认关闭。
若后续启用，只允许自愿激励视频解锁非主线番外，不得阻断主线。
