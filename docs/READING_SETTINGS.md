# 阅读设置与返回书桌

2026-10-08，当前工程main，V2开发切片。本批沿用用户确认的场景窗＋纸面和第三版音色，没有改变剧情JSON、证据条件或结局。纸面与按钮纹理继续使用同一件Image原图；文字、触摸区域和夜间颜色由Cocos排版。

## 实际行为

- 首页与正常阅读页都有“阅读设置”。三个字号、日间/夜间纸面、正常/较轻/静音录音音量，以及减少动态均可切换；音量不重新合成声音。
- 第一章纸面正文三档为设计稿46/54/60；其余原阅读面板基准48随同比例增大。真实物理手机、刘海/手势区域和阅读舒适度仍待验，不用设计字号冒充手机像素。
- 设置独立保存，不写入剧情存档，不增加属性、阅读历史、证据或已完成结局。无存档的首页调整设置不会创建剧情进度。
- 偏好存储失败时保持原文、允许当页使用并显示短提示；恢复后再次选择可保存。损坏偏好读取默认但不自动覆盖；未来版本原文不会被当前版本替换。剧情存档仍由原SaveManager处理。
- 调整字号/纸面时停留在原节点和滚动比例，当前已展开的信、照片背面、录音文字继续保持。展开状态是当前页面的表现记录，刷新仍按原交互入口打开，已存阅读偏移可恢复；不把展开状态变成剧情事实。
- 打开设置会暂停正在播放的录音。只改音量后返回保持暂停，由玩家继续播放；需重新排版时播放器安全销毁重建，不自动播放，不提前授予完整录音。
- 减少动态关闭短转场淡入和滚动惯性，仍由玩家点按继续，不自动跳段。
- 阅读页左上角“返回书桌”先停下滚动/播放，再保存当前进度；保存成功才回到Main。再次“继续”回到同一节点与阅读位置。保存失败留在当前页，保留原记录并提供重试。

## 本批修复

完整信件原先放在单个很高的Label中。大字号实际截图发现字形被拉伸，点按流程仍会通过。现按原有换行分别排版，保留全部原文与空行，不做文案改写；每个Label高度受内容自然限制。完整来源仍需要读至末尾并完成原操作。

## 核验方式

tools/browser-reading-settings.cjs从首页真实点按五种手机尺寸的桌面浏览器，切换六种字号/纸面组合、刷新、滚动、偏好写入失败/恢复；三种物件初始状态来自领域运行时真实动作路线，随后实际点按重排。检查文字完整、段落Label高度、未提前授予来源、实际AudioSource音量。

tools/browser-return-home.cjs从Boot开始实际阅读/滚动、返回书桌、续读，并注入剧情保存失败，检查原文和当前页保留、重试后返回。都不修改运行中的剧情状态，不代替TapTap真机。

存储边界另有三项核心测试。整游戏结构/类型和十章H5回归保留；机器记录在docs/validation，当前总进度见FINAL_PROGRESS。五种互动的完整物件表现、后续场景及手机验收继续待完成。
